# Phase 15.5 — UI/UX Polish

- Design tokens مشترک برای رنگ، سطح، border، radius و shadow
- Sidebar گروه‌بندی‌شده و خلوت‌تر برای عملیات، شبکه و مالی
- Bottom navigation واقعی برای موبایل فروشگاه
- Topbar سبک‌تر با CTA فروش جدید و context واضح کاربر
- Dashboard جدید با KPI hierarchy بهتر، status و quick actions
- Tables، forms، modals، empty/loading/error states یکپارچه‌تر
- Sales/Purchases/Inventory/Procurement polish بدون تغییر رفتار backend
- Mechanic UI بازطراحی‌شده برای mobile-first search، vehicle filter و result cards
- Focus-visible و affordance بهتر برای keyboard/accessibility
- بدون migration و بدون تغییر API
