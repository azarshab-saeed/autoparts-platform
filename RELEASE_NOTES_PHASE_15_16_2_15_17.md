# Release Notes — Mechanic Workshop + Trade Accounts + Management Intelligence

This bundle turns Vehicle Notebook into a network operating layer:

`Vehicle → Workshop Job → Installed Part → Network Store → Trade Account → Settlement → Management Intelligence`

### Phase 15.16.2
Mechanics can create vehicle notebooks, issue stable QR codes, run Job Cards, record service/part/labor, customer payments and due amounts, and commit completed work into permanent vehicle history.

### Phase 15.16.3
Each mechanic/store pair gets an isolated two-party ledger. Network purchase debt, returns, credits, adjustments and settlement requests require opposite-party confirmation before balance changes.

### Phase 15.17
Store owners get an actionable intelligence page: period sales, gross profit, discount, returns, below-margin and override signals, per-user performance for newly-attributed sales, slow/dead/reorder inventory, inactive/receivable customers, mechanic network exposure and suggested next actions.

No Modian protocol implementation is included in this release.
