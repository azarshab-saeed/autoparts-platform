# Phase 15.16.2 + 15.16.3 + 15.17 — Run & Acceptance

## Included

- Mechanic-created vehicle notebook + QR + owner code.
- Mechanic workshop Job Cards with service/part/labor/payment/due.
- Completed job facts are written into permanent vehicle history.
- Mechanic ↔ Store double-confirmed trade account and immutable ledger.
- Fulfilled network reservations can become trade-account charges only when an unpaid balance exists.
- Store management intelligence with user performance, margin/override, customer, inventory and mechanic-network signals.
- Phase 15.16.1 public owner route mount is enforced if it was not already applied.

## Acceptance flow

1. Mechanic login → `/mechanic/vehicle-notebook` → create a vehicle and copy/scan its QR.
2. `/mechanic/workshop` → create Job Card using vehicle token → add service, part, labor → record partial payment → complete job.
3. Owner opens `/vehicle/<token>` without login and sees completed service/part history (not workshop customer PII or mechanic/store balances).
4. Mechanic network order reaches `fulfilled` with unpaid amount → `/mechanic/accounts` → request "ثبت در حساب".
5. Store `/store/mechanics` → confirms the request → both sides see the same ledger balance.
6. Mechanic records settlement → store confirms → balance decreases.
7. Store `/store/intelligence` → verify sales/profit/discount/user performance, inventory/customer signals, mechanic receivable and suggested actions.

## Privacy / accounting invariants

- Public owner page never exposes owner phone/name/VIN, workshop debt, or mechanic-store trade balance.
- One store cannot see a mechanic's account with another store.
- Trade request has no effect on balance until the opposite party confirms it.
- A confirmed request creates one ledger entry; request_id is unique in the ledger.
- Positive mechanic-store balance means mechanic owes that store.
- Historical sales before Phase 15.17 are not guessed into a user; they remain explicitly unattributed.
- Modian integration remains deferred to the final integration gate.
