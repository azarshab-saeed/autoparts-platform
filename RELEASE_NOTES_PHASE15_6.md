# Release Notes — Phase 15.6 Adoption UX

این فاز ارزش محصول را به‌جای صرفاً ظاهر، روی رفتار روزانه کاربر متمرکز می‌کند.

- Network Value Dashboard: فروش و درخواست‌های ساخته‌شده توسط شبکه در ۳۰ روز گذشته.
- Action Center: اولویت‌های عملیاتی قابل اقدام روی صفحه اول.
- Import Center: مهاجرت امن catalog + opening inventory + selling price از CSV.
- Import idempotency و محافظت از موجودی زنده دارای سابقه.
- Opening inventory accounting با Journal متوازن.
- Saved Vehicle و Recent Search برای مکانیک/مصرف‌کننده در local storage.
- navigation جدید «ورود اطلاعات» برای owner/admin/warehouse.
- migration جدید `013_adoption_imports.sql` برای audit trail عملیات Import.

هیچ credential جدید یا seed جدیدی اضافه نشده است.
